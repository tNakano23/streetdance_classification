# streetdance_classification/sandbox/finetune

****************************************************************************************************************************
streetdance classification 用の Qwen 系モデルを作成するためのディレクトリです。

実行前に、まず以下のレポジトリをクローンしてください。

https://github.com/2U1/Qwen-VL-Series-Finetune.git

上記レポジトリでは、環境構築後に YAML ファイルを編集し、`.sh` ファイルを実行することでファインチューニングを行います。

環境構築用として、以下のファイルを用意しています。

- `pyproject.toml`
- `uv.lock`

必要に応じて参照してください。

また、実際に使用した設定・実行ファイルとして、以下を用意しています。

- `script/my_finetune_lora_vision_all.sh`
- `script/my_finetune_video.sh`

こちらも参考にしてください。


****************************************************************************************************************************
